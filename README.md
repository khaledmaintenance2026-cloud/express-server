# نظام صيانتي — السيرفر المحلي (Local Server)

سيرفر Node.js + PostgreSQL كامل لإدارة الصيانة والإنتاج والسلامة المهنية،
مصمم ليعمل داخل بيئة المصنع على جهاز واحد (كمبيوتر أو لابتوب) يبقى شغّالًا،
ويتصل به تطبيق الجوال (Flutter) وأي متصفح على نفس الشبكة.

**لا يحتاج أي خطوة `npm install`** — السيرفر مكتوب بالكامل بدون أي حزمة
خارجية (فقط وحدات Node.js المدمجة)، فتشغيله يعني ببساطة `node server.js`
بعد ضبط ملف الإعدادات.

---

## المتطلبات قبل البدء

1. **Node.js** إصدار ١٨ أو أحدث مثبَّت على الجهاز.
   تحقّقوا بفتح PowerShell وكتابة:
   ```powershell
   node --version
   ```
   لو ظهر رقم إصدار (مثل `v20.11.0`) فهو مثبَّت. لو ظهر خطأ "غير معروف"،
   حمّلوه من https://nodejs.org (اختاروا نسخة LTS) وثبّتوه بالإعدادات
   الافتراضية، ثم أغلقوا PowerShell وافتحوه من جديد.

2. **PostgreSQL 16** مثبَّت ويعمل، مع **pgAdmin 4** (يأتي معه تلقائيًا عادةً).
   إن كنتم قد أنشأتم بالفعل قاعدة بيانات باسم `sayanati_db` من pgAdmin —
   ممتاز، انتقلوا مباشرة للخطوة ٢ بالأسفل.

---

## الخطوة ١: وضع ملفات السيرفر على جهازكم

1. فكّوا ضغط الملف الذي أرسلناه (`sayanati-server.zip`) في مكان تتذكرونه
   بسهولة، مثل: `C:\sayanati-server`

---

## الخطوة ٢: إنشاء الجداول داخل قاعدة البيانات (مرة واحدة فقط)

عبر **pgAdmin 4**:

1. افتحوا pgAdmin 4، ووسّعوا الشجرة على اليسار حتى تصلوا لقاعدة
   `sayanati_db` تحت **Databases**.
2. اضغطوا عليها بزر الفأرة اليمين ← **Query Tool** (تفتح نافذة كتابة أوامر).
3. افتحوا ملف `schema.sql` (الموجود داخل مجلد السيرفر الذي فككتم ضغطه) بأي
   محرر نصوص (مثل Notepad)، انسخوا **كل محتواه**، والصقوه داخل نافذة
   Query Tool في pgAdmin.
4. اضغطوا زر التشغيل (▶ أو F5). يجب أن تظهر رسائل نجاح باللون الأخضر
   بالأسفل بدون أي خطأ أحمر.
5. للتأكد: وسّعوا `sayanati_db` ← **Schemas** ← **public** ← **Tables** —
   يجب أن تروا ١٢ جدولًا (`users`, `technicians`, `work_orders`, ...).

> يمكنكم إعادة تشغيل هذا الملف بأمان أي وقت لاحقًا (مثلاً بعد تحديث) —
> مصمَّم ليتجاوز الجداول الموجودة بدل أن يكرر إنشاءها أو يمسح بياناتها.

---

## الخطوة ٣: ضبط ملف الإعدادات (.env)

1. داخل مجلد السيرفر، انسخوا ملف `.env.example` وأعيدوا تسمية النسخة إلى
   `.env` فقط (بدون `.example`).
   في PowerShell (بعد الانتقال لمجلد السيرفر):
   ```powershell
   cd C:\sayanati-server
   Copy-Item .env.example .env
   ```
2. افتحوا `.env` بمحرر نصوص وعدّلوا هذه القيم:
   - `DB_PASSWORD` → كلمة مرور مستخدم `postgres` التي وضعتموها عند تثبيت
     PostgreSQL.
   - `JWT_SECRET` → أي نص عشوائي طويل من عندكم (مثال:
     `<نص-عشوائي-طويل-خاص-بكم>`) — يُستخدم لتشفير رموز الدخول، لا تشاركوه
     مع أحد.
   - `SEED_ADMIN_EMAILS` → بريدكم الإلكتروني (نفس البريد الذي ستسجّلون به
     أول حساب) — سيُعتمد تلقائيًا كـ"مدير نظام" فور التسجيل.
   - باقي القيم (`DB_HOST`, `DB_PORT`, `DB_NAME`, `PORT`) اتركوها كما هي
     إن كنتم استخدمتم نفس الإعدادات الافتراضية.

---

## الخطوة ٤: تشغيل السيرفر

في PowerShell:
```powershell
cd C:\sayanati-server
node server.js
```

يجب أن تظهر هذه الرسالة:
```
✅ نظام صيانتي يعمل الآن على المنفذ 3000
   افتح المتصفح على: http://localhost:3000
```

افتحوا هذا الرابط (`http://localhost:3000`) في أي متصفح على نفس الجهاز —
يجب أن تظهر لوحة تحكم صيانتي بالكامل مع شاشة تسجيل الدخول.

> **مهم**: اتركوا نافذة PowerShell هذه مفتوحة طالما تريدون السيرفر شغّالًا
> — إغلاقها يوقف السيرفر. للتشغيل الدائم على مدار الساعة، راجعوا قسم
> "التشغيل المستمر" بالأسفل.

---

## الخطوة ٥: إنشاء حساب المدير الأول

1. من نفس صفحة لوحة التحكم (`http://localhost:3000`)، اضغطوا "حساب جديد".
2. سجّلوا بنفس البريد الذي وضعتموه في `SEED_ADMIN_EMAILS` — ستدخلون فورًا
   كمدير نظام دون انتظار أي اعتماد.
3. من تبويب "إعدادات الموقع" يمكنكم اعتماد بقية الموظفين لاحقًا وتحديد دور
   كل واحد منهم (صيانة / إنتاج / سلامة).

---

## الخطوة ٦ (اختياري): الوصول من خارج المصنع عبر Cloudflare Tunnel

لو أردتم أن يعمل تطبيق الجوال من خارج شبكة المصنع (وليس فقط داخل نفس
الواي فاي)، تحتاجون نفقًا يفتح جهازكم للإنترنت بأمان:

1. حمّلوا `cloudflared` من
   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. في PowerShell (والسيرفر لا يزال شغّالًا في نافذة أخرى):
   ```powershell
   cloudflared tunnel --url http://localhost:3000
   ```
3. سيعطيكم رابطًا بصيغة `https://xxxxx.trycloudflare.com` — هذا الرابط هو
   ما تضعونه في تطبيق الجوال (مع إضافة `/api` بالنهاية).

⚠️ **تنبيه مهم**: هذا النوع من الروابط (Quick Tunnel) **مؤقت** — يتغيّر في
كل مرة تُعيدون تشغيل `cloudflared`. لرابط دائم لا يتغيّر أبدًا، يلزم
حساب Cloudflare مجاني + دومين (حتى لو فرعي مجاني) وإعداد "Named Tunnel" —
أخبرونا إن أردتم المساعدة في هذه الخطوة لاحقًا.

---

## الخطوة ٧: ربط تطبيق الجوال بالسيرفر

1. افتحوا مشروع تطبيق Flutter (النسخة المحدَّثة `sayanati_app_local_
   server.zip` التي أرسلناها في المراجعة السابقة).
2. افتحوا الملف `lib/services/constants.dart` وعدّلوا قيمة `kApiBaseUrl`:
   - للاستخدام داخل شبكة المصنع فقط: عنوان IP الجهاز الذي يشغّل السيرفر،
     مثل `http://192.168.1.100:3000/api` (لمعرفة عنوان IP جهازكم، اكتبوا
     `ipconfig` في PowerShell وابحثوا عن "IPv4 Address").
   - للوصول من خارج المصنع: رابط Cloudflare من الخطوة السابقة + `/api`.
3. ارفعوا المشروع المعدَّل لمستودع GitHub الخاص بكم كما فعلتم سابقًا —
   سيُبنى APK جديد تلقائيًا يحمل الإعداد الجديد.

---

## التشغيل المستمر على مدار الساعة (بدون إبقاء PowerShell مفتوحة يدويًا)

الطريقة الأبسط: حزمة `pm2` (تُشغّل السيرفر في الخلفية وتعيد تشغيله تلقائيًا
لو تعطّل أو أُعيد تشغيل الجهاز). ملاحظة: هذه الحزمة الوحيدة التي تحتاج
تثبيتًا عبر الإنترنت (السيرفر نفسه لا يحتاجه، لكن هذه أداة تشغيل اختيارية):

```powershell
npm install -g pm2
cd C:\sayanati-server
pm2 start server.js --name sayanati
pm2 save
pm2-startup install
```

هذا يجعل السيرفر يعمل تلقائيًا حتى بعد إعادة تشغيل الجهاز، بدون حاجة لفتح
PowerShell يدويًا في كل مرة.

---

## هيكل المشروع

```
sayanati-server/
  schema.sql           بنية قاعدة البيانات الكاملة (تُشغَّل مرة واحدة)
  server.js            نقطة بدء تشغيل السيرفر
  .env                 إعداداتكم الخاصة (لا تُشاركوه أو ترفعوه لأي مكان عام)
  config/db.js         الاتصال بقاعدة البيانات
  lib/                 أدوات داخلية (اتصال PostgreSQL، خادم HTTP، JWT) بدون أي حزمة خارجية
  middleware/           التحقق من تسجيل الدخول والصلاحيات
  routes/               كل مسارات الـ API (auth, work-orders, safety-permits, ...)
  services/webhooks.js  إرسال التنبيهات لخدمات خارجية (واتساب عبر بوابة وسيطة مثلًا)
  public/index.html     لوحة التحكم (تفتح من المتصفح مباشرة على المنفذ 3000)
```

## استكشاف الأخطاء الشائعة

- **"node : اسم غير معروف"** → Node.js غير مثبَّت أو تحتاجون إعادة فتح
  PowerShell بعد التثبيت.
- **السيرفر يعطي خطأ اتصال بقاعدة البيانات فور التشغيل** → تأكدوا أن
  PostgreSQL نفسه يعمل (من pgAdmin، حاولوا الاتصال بـ `sayanati_db` أولًا)
  وأن `DB_PASSWORD` في `.env` صحيحة.
- **تطبيق الجوال يقول "تعذّر الاتصال بالسيرفر"** → تأكدوا أن الجوال والجهاز
  الذي يشغّل السيرفر على نفس شبكة الواي فاي (لو تستخدمون IP محلي)، وأن
  `kApiBaseUrl` مطابق تمامًا (بما فيه `/api` بالنهاية).
